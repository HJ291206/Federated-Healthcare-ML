## Audit notes (2026-10-15)

Issues found and fixed during the audit:

1. `python -m ml.run jax --device …` was silently ignored because the JAX experiment built its PyTorch `MLPTrainConfig` without the `device` field; fixed (`ml/jax_cnn/experiment.py`), and `--device` for `federated`/`dp` now targets the centralized reference MLP (`reference_training.device`).
2. The dashboard API imported `load_mlp` from the SHAP module, making `shap` a hidden dependency of the API; `load_mlp` moved to `ml/models.py`.
3. No end-to-end test existed; `tests/test_e2e_smoke.py` now runs the federated pipeline on the real CSV (2 rounds, 1 reference epoch) and checks artefacts, leakage, byte accounting and metric consistency.

No errors were found in the FedAvg weighting, the FedProx objective, the partitioning, the preprocessing, the threshold protocol or the DP accounting path during code review; the corresponding unit tests were re-run (see README §9).
