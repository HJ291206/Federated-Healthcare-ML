## Why recall on the diabetes class matters

A false negative is a person with diabetes whom the model calls healthy. In a screening use case that person is not referred for a confirmatory test (e.g. HbA1c), and untreated diabetes leads to the complications described in `data/README.md`. A false positive costs a follow-up test. Because of this asymmetry, recall (sensitivity) on class 1 is the primary threshold-dependent metric, and accuracy is not: predicting 'no diabetes' for everyone already reaches 86.07% test accuracy with zero recall. Recall must be read together with class-1 precision, since raising recall by lowering the threshold increases false positives; the `val_recall_0.80` operating point makes this trade-off explicit. These are research models on self-reported survey data, not a validated screening tool.
