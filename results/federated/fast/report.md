## Caveats

- Training time is wall-clock time of a sequential single-process simulation on CPU; in a real deployment clients would train in parallel and network latency would dominate.
- The centralized MLP uses Adam with early stopping (the Phase-2 recipe); federated methods use plain SGD for a fixed number of rounds, the standard FedAvg/FedProx client optimizer.
- Per-round test metrics are logged for convergence plots only; no round, hyperparameter or threshold is chosen using the test set.
